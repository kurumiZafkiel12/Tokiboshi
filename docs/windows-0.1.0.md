# Windows 0.1.0 候选版

本轮先更新 Windows 桌面版，Android 继续使用已发布版本。此文不是发布公告。

## 工作台与管理

- 统一深色/浅色、酒红强调色、分层卡片和紧凑连接栏；导航、抽屉、列表变化延续动效档位与减少动画设置。
- 工作台保留可调整组件，区分内核运行、接管方式与连通性；内核运行不等于外网可用。
- 节点来源筛选与策略组筛选独立；筛选不切换出口，使用策略组须显式确认。大列表按需构建。
- 订阅支持名称/地址/更新间隔编辑，默认隐藏地址。更新失败保留旧数据与失败状态；运行代理时延后自动更新。
- 节点更新优先恢复同来源的唯一内容匹配，再恢复唯一端点匹配；歧义时清除选择并要求重新选择。跨来源同名节点不自动替换。
- 保留链接、文件、剪贴板/文本、二维码图片与自定义节点导入；完整订阅兼容门禁仍然生效。

## 设置与常用功能

- 常规与连接：启动/托盘/自动连接、请求设置、端口、局域网监听、控制器、认证与内核路径。
- 外观动效：主题、密度、动画档位及减少动画。
- 分流与 DNS：完整域名、域名后缀/关键词、IP 网段、进程、目标端口，支持代理/直连/拒绝；启停、排序、删除。全局/直连模式优先于自定义规则，自定义规则优先于配置规则。
- DNS 覆盖支持 HTTPS/TLS/TCP/UDP，只影响内置模板；完整订阅继续使用订阅 DNS。进程规则是否命中还取决于内核进程识别条件。
- 测速 URL/超时可调整。内核启动后使用真实出口 URL 测试；停止时只做 TCP 端口探测，不以此判断代理可用，UDP 协议不作虚假 TCP 测试。
- 请求页面增加 TCP/UDP 筛选、流量/时间排序、暂停快照和连接详情；保留关闭连接、日志和诊断能力。
- 本地完整配置备份/恢复：恢复前预览、停止连接后导入、原子保存；不导入外部内核路径、本机控制器身份或自动启动意图。备份包含订阅和节点凭据，需自行安全保管。
- Ctrl+K 查找节点、Ctrl+I 导入、Ctrl+, 设置。

## 范围

参考 FlClash、Clash Verge Rev、Karing、v2rayN 的共同能力，不复制其实现或假设不同内核功能相同。

不在本轮承诺多完整配置并行合并、全套稳定 ID 迁移、订阅服务、协议转换、强制 ECH、WebDAV 或 Android 新版。完整规则兼容性仍按现有支持范围明确报错。

保留中文安装、安装路径范围内关闭旧进程、覆盖和清理已知退役程序文件的升级流程；用户数据保留。候选包需通过 Windows CI，不能用 Linux 测试代替真实桌面 GUI/UAC/TUN 验证。
