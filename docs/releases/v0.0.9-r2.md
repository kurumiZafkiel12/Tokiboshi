# Tokiboshi 0.0.9 修订版 r2 · 多方式导入与流畅交互

应用版本 **0.0.9+10**，标题 **Tokiboshi · 時の星**。这是独立修订包，旧版 v0.0.9 保留供追溯。

- **修复订阅导入整批失败**：智能导入遇到无法转换的规则或 DNS 时，展示具体原因与已识别节点数量，明确确认后可仅导入节点；不会静默换成内置规则。选择随来源保存，后续更新沿用；也可停止代理后重试完整配置。严格完整配置模式仍拒绝不兼容内容，并保留原配置。
- **统一导入入口**：链接、剪贴板/文本、配置文件、二维码图片/剪贴板图片、自定义节点；可读取 YAML/JSON 完整配置、节点列表及常见客户端导入链接，支持一次粘贴多条链接。二维码支持本地图片与 Windows 剪贴板位图，本轮不包含摄像头扫描或屏幕区域扫描。
- **扩展规则转换**：Clash classical YAML/text provider 的支持项，以及源/目标端口、网络、进程名/路径、源地址和 LAN 私有地址规则。MRS、fake-ip 与未支持的高级 DNS 仍明确报告，不声称完整兼容。
- **完善常规设置并接线**：当前用户开机自启、托盘静默启动、每次打开自动连接、恢复上次运行状态、按程序运行状态连接；订阅 User-Agent、TLS 校验、检查更新；局域网代理、HTTP/SOCKS 认证、局域网控制器与密钥复制。按需功能只停止它建立的连接，手动停止后本轮不自动重连；TUN 提权仍需手动授权。
- **更细腻的动效**：组件分批入场、卡片悬停、节点排序位移、真实流量数字与曲线平滑过渡、导入面板高度过渡；保留页面、导航、抽屉、连接光流及选中态过渡。支持流畅/轻量/精简三档及系统减少动态；快速操作时退出中的旧页面不接收点击。
- **保留配置**：取消导入、网络迟到结果、保存失败均保护既有节点和来源。文件预览限长不截断实际导入内容，重复提交不会重复关闭窗口。

## 升级说明

- 推荐简体中文安装包：按安装路径自动关闭旧进程、覆盖程序、按清单清理退役程序文件，保留配置与恢复文件。安装程序未作 Authenticode 签名，可通过 SHA256SUMS 校验。
- 随包提供官方摘要校验的 sing-box 1.14.4。更新检查仅打开下载页，不静默安装；新设置默认保留旧版行为，打开应用每次连接可在设置中启用。
- 开启局域网控制器始终需要密钥，开启代理认证需填写用户名和密码。网络接入设置在运行中修改会重启内核。关闭 TLS 校验只影响订阅/规则下载，不修改节点 TLS。
- 自动化布局与原生探针不替代用户设备的 GUI、文件选择器、UAC、TUN、UDP 和真实订阅验收。稳定身份迁移、完整 T069 缓存继续单独推进。
