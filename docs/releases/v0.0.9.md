# Tokiboshi v0.0.9 · 小组件工作台

按用户提供的「方案 B」设计，将 HTML 交互原型实现为原生 Flutter 界面。

- 重做桌面外壳：深灰酒红配色、红金角色细节、蝴蝶结标、紧凑侧栏、原生窗口控制、顶部操作区和底部状态栏。
- 首页改为四个信息组件：连接状态、真实流量、订阅配置、运行详情。状态固定左上，其余支持拖动/箭头重排、恢复布局并保存。
- 底部固定出口节点与连接组件，加入临时节点选择窗、搜索/来源筛选/排序、重新连接与启动取消。
- 节点页支持来源、provider 与策略组筛选、列表/卡片视图、延迟排序、密度设置、详情抽屉与删除确认。
- 订阅页改为来源卡片，提供批量更新、识别诊断和脱敏地址。规则页区分保存配置预览、运行内核返回规则及本地文件就绪数量；请求页展示真实连接并可关闭；日志页支持级别/文本筛选、跟随、清空视图与脱敏导出。
- 外观支持深浅主题、流畅/轻量/精简动效、跟随系统减少动态、角色细节/连接光流独立开关；连接光流限制在卡片内，页面切换、选中态与组件排序均有过渡。
- 完整配置可在停止代理后明确激活，按来源隔离规则与出口；多个配置未选择时拒绝猜测，切换来源不会沿用外源同名节点。运行中先停止再更换配置，避免静默换规则。
- 保留 v0.0.8 的内核启动、提权交接、订阅规则转换、中文覆盖升级与数据恢复逻辑。新增偏好向后兼容，无须清空用户数据。

## 升级与行为

- 推荐中文安装版：按安装路径自动关闭旧进程、覆盖程序、按清单清理退役程序文件，保留节点、设置及恢复文件。安装程序未作 Authenticode 签名。
- 安装包随附固定的官方校验 sing-box 1.14.4，缺失时仍可下载修复；普通权限 TUN 启动需手动授权管理员重启。
- 流量、延迟、请求、规则状态来自实际控制器或本地文件。停止/不可达明确显示不可用，不使用原型的合成数值、固定 3/3 或假成功。
- 切换完整配置需先停止代理，再选择配置与所属出口后启动；节点订阅无需激活，不会替换完整配置规则。配额/流量套餐和候选配置版本没有完整数据模型，界面不伪造这些数据。MRS 等既有格式限制不在本次扩展。
- 自动化检查不替代用户设备上的 GUI、UAC、TUN、真实订阅及 UDP 验收。现有稳定 ID 迁移与完整 T069 缓存/统一导入任务继续单独推进。
