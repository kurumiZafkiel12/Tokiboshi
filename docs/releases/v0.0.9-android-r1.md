# Tokiboshi Android · 0.0.9 r2

Android 7.0（API24）及以上，应用版本0.0.9 / build11。这是0.0.9 r2的首个Android发行，独立tag便于记录移动端源码；Windows r2安装包保留。

- 手机布局保留深灰酒红配色、角色细节、四个入口、卡片入场与数字/曲线过渡，支持流畅/轻量/精简和系统减少动态；窄屏、横屏也可操作。
- 链接、剪贴板/文本、配置文件、二维码图片/剪贴板图片、自定义节点导入；完整配置不兼容时，明确确认后可仅导入节点，保留来源更新方式。
- 共用Rust解析/配置与订阅展开，嵌入固定sing-box/libbox1.14.4。通过Android系统VPN授权、前台通知、socket保护和物理网络监视接管IPv4/IPv6流量，不需要root。
- 提供节点选择/内核测速、规则/全局/直连模式、真实流量/请求/规则/日志，以及主题、动效、默认打开应用自动连接（可关闭并保留偏好）、订阅UA/TLS等手机设置。运行中切换节点由真实控制器执行。
- 使用正式发布签名，三种ABI分别构建，提供SHA256。签名恢复材料另行加密保管，未使用debug签名冒充正式安装包。

## 验证范围与边界

使用实际Android系统VPN、Flutter界面、Rust桥接和Go内核验证；独立shell UID发送请求，覆盖IPv4/IPv6、切换节点/模式、后台、重复启停与UDP DNS。三ABI还需通过版本、正式签名、原生库机器类型、CRC及16KiB对齐检查。具体构建与产物摘要以发行验证附件和AI-Workspace报告为准，不把模拟器当成所有手机/OEM或真实公网节点验收。

本轮二维码为图片/剪贴板，不含摄像头或屏幕框选；MRS/fake-ip/高级DNS、完整稳定ID迁移和统一缓存仍保留原有边界。不在手机中提供Windows注册表、托盘或UAC设置。Android组合发行按GPL-3.0-or-later，完整许可证与对应源码已提供；原组件许可保留。
