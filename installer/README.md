# Windows 中文安装与升级

默认安装界面为简体中文；Inno Setup 6.5+。`/DOutputSuffix=-zh` 可生成中文附加安装包文件名。v0.0.5 中文包复用固定 SHA256 的正式便携包，没有重新编译或替换应用 DLL/EXE。

升级在提取新文件前按完整安装路径识别 Tokiboshi 和其内核，先请求关闭窗口，仍未退出则限定路径/父进程身份结束进程。不会全局 taskkill 同名核心。只有证实本地代理监听属于本次停止的内核，才清除仍指向它的系统代理设置。

`installer-files.json` 记录本版实际安装文件。升级前保存旧清单，安装完成后只删除旧清单有、新清单没有的程序文件；旧版无清单时，使用已验证 v0.0.5 便携包（SHA256 `69fea32a5e0b11c314a79e71ab4ce9ed670220c0ba5e902279f57044a5890804`）的 23 文件清单。拒绝越界路径和重解析点，不递归清空安装目录。未知用户文件以及 APPDATA 中的节点、设置、tmp/bak 恢复文件保留。清理失败有提示及非零安装退出码。

`tests/upgrade-helper.ps1` 验证进程范围、代理范围、退役文件和数据保留；仅写隔离的 HKCU 测试键，不改变真实系统代理。`tests/upgrade-install.ps1` 使用真实旧安装包后执行静默覆盖，检查替换的文件摘要、语言、重复安装、退役清理和配置保留。旧 GUI 占用由安装路径中的受控进程模拟，不等于用户完整 GUI/WebView/TUN 验收。

中文翻译来源与固定版本见 [languages/README.md](languages/README.md)。
